# Контент-блоки для статьи: «Важно знать», «Миф/Реальность», «Цитата»

Дата: 2026-07-05
Ветка: feature/search-results-page (блоки статьи)

## Цель

Добавить редакторам возможность собирать тело статьи из трёх новых элементов,
которые уже нарисованы в макете `страница_статья` (Pencil, фрейм `chdJU`):

1. **«Важно знать»** — информационная плашка (callout).
2. **«Миф / Реальность»** — заголовок мифа + две карточки-сравнения.
3. **«Цитата»** — оформленная цитата с автором (кастомизация ядрового `core/quote`).

Блок «Новость» из первоначального запроса отложен (отдельное обсуждение).

## Конвенции темы (следуем существующему паттерну)

Все текущие блоки — это **ACF-блоки** (пример: `sputnik/faq`):

- `src/blocks/block-<name>/` с файлами `block.json`, `render.php`, `index.js`,
  `style.scss`, `editor.scss`.
- `block.json` содержит секцию `acf`:
  ```json
  "acf": {
    "blockVersion": 3,
    "autoInlineEditing": true,
    "mode": "preview",
    "renderTemplate": "render.php"
  }
  ```
- Поля хранятся в `acf-json/group_<id>.json`, location — `block == sputnik/<name>`.
- `render.php` выводит поля через `get_field()`.
- Регистрация блоков — автоматическая (`wp_register_block_types_from_metadata_collection`
  по манифесту из `build/`), правки в `functions.php` для новых ACF-блоков не нужны.
- Сборка: `npm run build` (компилирует `src/blocks/*` → `build/blocks/*`).

**Инлайн-редактирование.** `autoInlineEditing: true` даёт ACF возможность править
простые поля (`text`, `textarea`) прямо в превью блока на канвасе. Те же поля
остаются доступными во вкладке ACF (боковая панель / под блоком). Поэтому все
текстовые поля делаем типом `text`/`textarea` — они и инлайн, и в панели.

## Блок 1 — `sputnik/important` («Важно знать»)

Callout-плашка: круглая иконка + подпись-заголовок + текст.

**Поля ACF (группа `location: block == sputnik/important`):**

| name      | тип      | по умолчанию   | инлайн |
|-----------|----------|----------------|--------|
| `title`   | text     | «Важно знать»  | да     |
| `content` | textarea | —              | да     |

**Разметка (`render.php`):**
```html
<div class="imp">
  <span class="imp__icon" aria-hidden="true">…i…</span>
  <div class="imp__body">
    <p class="imp__title">{title}</p>
    <div class="imp__text">{content, wpautop}</div>
  </div>
</div>
```

**Стиль (из макета `F3LEz`):**
- контейнер: фон `#fbf9f5`, радиус `14px`, паддинг `~24px 28px`, `flex`, `gap 16px`.
- иконка: круг `40px`, фон `#ffffff`, глиф «i» цветом `#143358`.
- заголовок: `#143358`, `14px`, `700`, `letter-spacing .5px`.
- текст: `#2e3e55`, `15px`, `line-height 1.6`.

Если оба поля пусты — `render.php` ничего не выводит.

## Блок 2 — `sputnik/myth` («Миф / Реальность»)

Один блок = **один миф**: заголовок + две карточки (не повторитель — чтобы добавить
ещё миф, редактор вставляет новый блок; так проще и полностью инлайн).

**Поля ACF (группа `location: block == sputnik/myth`):**

| name            | тип      | по умолчанию | инлайн |
|-----------------|----------|--------------|--------|
| `heading`       | text     | «Миф 1. …»   | да     |
| `myth_label`    | text     | «Миф»        | да     |
| `myth_text`     | textarea | —            | да     |
| `reality_label` | text     | «Реальность» | да     |
| `reality_text`  | textarea | —            | да     |

**Разметка (`render.php`):**
```html
<div class="myth">
  <h3 class="myth__heading">{heading}</h3>
  <div class="myth__cards">
    <div class="myth__card myth__card--myth">
      <span class="myth__badge myth__badge--myth">✕</span>
      <span class="myth__label">{myth_label}</span>
      <div class="myth__text">{myth_text, wpautop}</div>
    </div>
    <div class="myth__card myth__card--reality">
      <span class="myth__badge myth__badge--reality">✓</span>
      <span class="myth__label">{reality_label}</span>
      <div class="myth__text">{reality_text, wpautop}</div>
    </div>
  </div>
</div>
```

**Стиль (из макета `OO7jV` / `UDJTE` / `g76wc`):**
- заголовок `.myth__heading`: `#143358`, `20px`, `700`.
- карточки в ряд, `gap 16px`, каждая радиус `14px`, паддинг `~24px`.
- карточка «Миф»: фон `#fbf2f2`; бейдж-круг `24px` фон `#e6bbc0`, глиф ✕ `#b93a46`;
  подпись `#b93a46`, `11px`, `700`, `letter-spacing 1px`, uppercase.
- карточка «Реальность»: фон `#eef6f2`; бейдж-круг `24px` фон `#bfdbc9`, глиф ✓ `#2f7d5b`;
  подпись `#2f7d5b`, `11px`, `700`, `letter-spacing 1px`, uppercase.
- текст карточек: `#2e3e55`, `15px`, `line-height 1.55`.
- мобильные (`<= 800px`): карточки в столбец (`flex-direction: column`).

Иконки-бейджи ✕/✓ и цвета фиксированы CSS (редактор их не трогает).

## Блок 3 — кастомизация `core/quote` (стиль «Спутник»)

Не новый блок, а **стиль-вариация** ядрового блока «Цитата». Редактор пользуется
стандартной цитатой ядра (текст + подпись через `<cite>`) — редактирование инлайн
из коробки; в панели стилей выбирает вариацию «Спутник».

**Регистрация:** `register_block_style( 'core/quote', [...] )` в `functions.php`
(имя стиля `sputnik`, лейбл «Спутник»). Класс на разметке — `is-style-sputnik`.

**Стиль (из макета `MjNiL`), селектор `.wp-block-quote.is-style-sputnik`:**
- левая граница `4px solid #e63946`, без фона, паддинг слева `~32px`.
- текст цитаты: `Georgia`, `italic`, `~21px`, `#143358`, `line-height 1.64`.
- подпись `cite`: `Inter`, `13px`, `500`, `#6b7a8f`, `letter-spacing .3px`, не курсив.

**Где живёт CSS:** новый партиал `src/scss/parts/quote.scss`, подключённый в
`main.scss` (фронт). Для отображения в редакторе — те же правила добавляются в
`src/scss/editor.scss`. (ACF-блоки 1–2 используют собственные `style.scss`;
цитата — ядровый блок, поэтому её стиль в общей теме, а не в папке блока.)

## Соответствие токенам темы

Макет использует конкретные hex-цвета, близкие к токенам темы, но не совпадающие
точно (например текст `#2e3e55` vs `--color-text-primary #1D3658`). Для точного
соответствия макету используем hex из макета внутри `style.scss` блоков; там, где
значение точно совпадает с токеном (`--color-*`), ссылаемся на токен.

## Проверка (после реализации)

- `npm run build` проходит без ошибок; в `build/blocks/` появились `sputnik-important`,
  `sputnik-myth`.
- `php -l` для обоих `render.php` (через `wp-env run cli`, см. память проекта).
- Оба блока находятся в инсёртере, ставятся на страницу, поля правятся инлайн и в панели.
- Пустые блоки ничего не ломают (ранний `return`).
- Цитата: вариация «Спутник» появляется в переключателе стилей и применяет оформление.
- Визуально три блока совпадают с макетом `chdJU` на десктопе и в мобильной ширине.
